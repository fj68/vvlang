Home / Module lib/std/record.vv

The `record` module provides utilities for working with records (key-value maps).
Records are unordered collections of fields, where keys are typically strings or integers.

Exports

function keys(r)

Returns a list of all keys in the record.

Example:
```vv
let r = {a: 1, b: 2}
record.keys(r) // ["a", "b"]
```

function values(r)

Returns a list of all values in the record.

Example:
```vv
let r = {a: 1, b: 2}
record.values(r) // [1, 2]
```

function has(r, k)

Checks if the record contains the specified key.

Example:
```vv
let r = {foo: "bar"}
record.has(r, "foo") // true
record.has(r, "baz") // false
```

9. Modules and Program Structure

Module Structure

A vv file typically represents a module. Code is executed sequentially from top to bottom.

Importing Modules

To use code from another module, you use the import name from "path" syntax.

import math from "./math_utils.vv"
let result = math.add(10, 5)

Exporting Variables

By default, variables declared in a module are private to that module. To make them accessible to code that imports the module, prefix the declaration with pub.

pub let PI = 3.14159

Exporting Functions

Similarly to variables, named functions are private by default. You can also export functions using the pub modifier so they can be called from importing modules. 

pub fun calculate_area(radius)
    return PI * radius * radius
end

System Imports

Standard library modules can be imported by specifying the std/ prefix followed by the module name. 

import console from "std/console.vv"
console.print("Hello, system!")

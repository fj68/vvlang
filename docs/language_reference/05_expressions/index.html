5. Operators and Expressions

In this chapter

  • Arithmetic Operators
  • Comparison Operators
  • Logical Operators
  • Prefix and Infix Expressions

Arithmetic Operators

vv supports standard arithmetic operations on numbers:

  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: /

Comparison Operators

Comparison operations evaluate to a boolean value (true or false):

  • Equal: ==
  • Less Than: <
  • Less Than or Equal: <=

Logical Operators

Logical operators work on boolean values.

  • Logical NOT: not(expr)
  • Logical AND: and
  • Logical OR: or

Prefix and Infix Expressions

Expressions can be combined using prefix (e.g., not(true), -5) and infix (e.g., 1 + 2, a == b) operators.

Module std/int.vv

The int module provides standard utilities for integer numbers.

Table of Contents

  • to_string
  • to_float

Exports

fun to_string(i) extern "native"

Converts an integer to its string representation.

Example:

int.to_string(42) // "42"

fun to_float(i) extern "native"

Converts an integer to a floating-point number.

Example:

int.to_float(42) // 42.0

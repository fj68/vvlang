lib/std

  • lib/std/bool.vv — The `bool` module provides standard utilities for boolean values.
  • lib/std/char.vv — The `char` module provides utilities for working with characters.
  • lib/std/console.vv — The `console` module provides standard input and output utilities.
  • lib/std/float.vv — The `float` module provides standard utilities for floating-point numbers.
  • lib/std/int.vv — The `int` module provides standard utilities for integer numbers.
  • lib/std/list.vv — The `list` module provides utilities for working with lists (arrays).
  • lib/std/math.vv — The `math` module provides standard mathematical functions.
  • lib/std/record.vv — The `record` module provides utilities for working with records (key-value maps).
  • lib/std/sys.vv — The `sys` module provides system-level capabilities and interpreter control.

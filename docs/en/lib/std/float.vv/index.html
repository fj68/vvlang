The `float` module provides standard utilities for floating-point numbers.

Exports

extern to_string

Converts a floating-point number to its string representation.

Example:
```vv
float.to_string(3.14) // "3.14"
```

extern to_int

Converts a floating-point number to an integer by truncating toward zero.

Example:
```vv
float.to_int(3.14) // 3
float.to_int(-2.5) // -2
```

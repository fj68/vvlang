Module std/char.vv

The char module provides utilities for working with characters. Characters are typically represented by single quotes.

Exports

fun to_upper(c) extern "native"

Converts a character to its uppercase equivalent.

Example:

char.to_upper('a') // 'A'
char.to_upper('1') // '1'

fun to_lower(c) extern "native"

Converts a character to its lowercase equivalent.

Example:

char.to_lower('A') // 'a'
char.to_lower('!') // '!'

fun is_digit(c) extern "native"

Checks if a character is an ASCII decimal digit ('0'-'9').

Example:

char.is_digit('5') // true
char.is_digit('a') // false

fun is_space(c) extern "native"

Checks if a character is a whitespace character (e.g., space, tab, newline).

Example:

char.is_space(' ')  // true
char.is_space('\n') // true
char.is_space('a')  // false

fun to_bytes(c) extern "native"

Converts a character to a list of its UTF-8 byte values.

Example:

char.to_bytes('a') // [97]
char.to_bytes('€') // [226, 130, 172]

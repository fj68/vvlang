vv Tooling & CLI

The vv command line tool provides several subcommands for development, testing, and package management.

vv run

Run .vv scripts and programs.

vv test

Run tests with built-in test discovery.

vv doc

Generate HTML documentation from source code.

vv get

Download and install remote modules.

vv vendor

Vendor dependencies for reproducible builds.

vv clean

Manage the global module cache.

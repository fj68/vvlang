The `list` module provides utilities for working with lists (arrays).
Lists are ordered, mutable collections of elements of any type.

Exports

function zip(xs, ys)

Pairs elements of two lists based on their index. The longer list is truncated to the shorter list's length.

Example:
```vv
let a = [1, 2]
let b = ["a", "b"]
list.zip(a, b) // [[1, "a"], [2, "b"]]
```

function every(xs, f)

Checks if all elements in the list satisfy the applied condition `f(index, element)`.

Example:
```vv
let l = [2, 4, 6]
list.every(l, fun (i, x) x % 2 == 0 end) // true
```

function some(xs, f)

Checks if at least one element in the list satisfies the applied condition `f(index, element)`.

Example:
```vv
let l = [1, 2, 3]
list.some(l, fun (i, x) x % 2 == 0 end) // true
```

function fold_right(xs, init, f)

Applies a function against an accumulator and each element (from right to left) to reduce it to a single value.
The applied function receives the accumulator, the index, and the element as arguments.

Example:
```vv
let l = ["a", "b", "c"]
list.fold_right(l, "", fun (acc, i, x) acc + x end) // "cba"
```

function head(xs)

Returns the first element of a list.

Example:
```vv
let l = [1, 2, 3]
list.head(l) // 1
```

function flat(xs)

Flattens a list of lists into a single continuous list.
Note: Only flattens exactly one level deep.

Example:
```vv
let l = [[1, 2], [3, 4]]
list.flat(l) // [1, 2, 3, 4]
```

function min(xs, f)

Returns the element that produces the minimum value when `f(element)` is applied.

Example:
```vv
let l = [1, 5, 2]
list.min(l, fun (x) x end) // 1
```

function partition(xs, f)

Splits a list into two lists: one containing elements that satisfy the condition `f(index, element)`, and another for elements that don't.

Example:
```vv
let l = [1, 2, 3, 4]
list.partition(l, fun (i, x) x % 2 == 0 end) // [[2, 4], [1, 3]]
```

function find_index(xs, f)

Returns the index of the first element in the list that satisfies the condition `f(index, element)`.
Returns `-1` if no such element is found.

Example:
```vv
let l = [1, 2, 3]
list.find_index(l, fun (i, x) x % 2 == 0 end) // 1
```

function find_pattern(xs, ys)

Searches for a sub-list pattern within the list and returns the start index.
Returns `-1` if not found.

Example:
```vv
let l = [1, 2, 3, 4]
list.find_pattern(l, [2, 3]) // 1
```

extern push

Adds a value to the end of a list.
Returns the modified list.

Example:
```vv
let l = [1, 2]
list.push(l, 3) // [1, 2, 3]
```

function each(xs, f)

Iterates over each element in a list and applies a function to it.
The applied function receives the index and the element as arguments.

Example:
```vv
let l = ["a", "b"]
list.each(l, fun (i, x) console.print(x) end)
```

function map(xs, f)

Returns a new list with the results of applying a function to every element.
The applied function receives the index and the element as arguments.

Example:
```vv
let l = [1, 2, 3]
list.map(l, fun (i, x) x * 2 end) // [2, 4, 6]
```

function reverse(xs)

Returns a new list with the elements of the original list in reverse order.

Example:
```vv
let l = [1, 2, 3]
list.reverse(l) // [3, 2, 1]
```

function take_while(xs, f)

Takes elements from the beginning of the list as long as they satisfy the condition `f(index, element)`.
Stops at the first element that fails the condition.

Example:
```vv
let l = [1, 2, 3, 4]
list.take_while(l, fun (i, x) x < 3 end) // [1, 2]
```

extern shift

Removes and returns the first element from a list.

Example:
```vv
let l = [1, 2, 3]
list.shift(l) // 1
// l is now [2, 3]
```

extern unshift

Adds a value to the beginning of a list.
Returns the modified list.

Example:
```vv
let l = [2, 3]
list.unshift(l, 1) // [1, 2, 3]
```

extern replace

Replaces occurrences of a sub-list pattern within a list with another pattern.
Returns a new list.

Example:
```vv
let l = [1, 2, 3, 2, 3, 4]
list.replace(l, [2, 3], [5, 6]) // [1, 5, 6, 5, 6, 4]
```

function filter(xs, f)

Returns a new list containing only elements that satisfy the provided testing function.
The testing function receives the index and the element as arguments.

Example:
```vv
let l = [1, 2, 3, 4]
list.filter(l, fun (i, x) x % 2 == 0 end) // [2, 4]
```

function fold_left(xs, init, f)

Applies a function against an accumulator and each element (from left to right) to reduce it to a single value.
The applied function receives the accumulator, the index, and the element as arguments.

Example:
```vv
let l = [1, 2, 3]
list.fold_left(l, 0, fun (acc, i, x) acc + x end) // 6
```

function join(xs, sep)

Joins all elements of a list, placing the provided separator between each element.

Example:
```vv
let l = [1, 2, 3]
list.join(l, 0) // [1, 0, 2, 0, 3]
```

function find(xs, f)

Returns the first element in the list that satisfies the condition `f(index, element)`.

Example:
```vv
let l = [1, 2, 3]
list.find(l, fun (i, x) x % 2 == 0 end) // 2
```

function drop_while(xs, f)

Drops elements from the beginning of the list as long as they satisfy the condition `f(index, element)`.
Returns the remaining elements starting from the first element that fails the condition.

Example:
```vv
let l = [1, 2, 3, 4]
list.drop_while(l, fun (i, x) x < 3 end) // [3, 4]
```

extern pop

Removes and returns the last element from a list.

Example:
```vv
let l = [1, 2, 3]
list.pop(l) // 3
// l is now [1, 2]
```

function tail(xs)

Returns a new list containing all elements except the first one.

Example:
```vv
let l = [1, 2, 3]
list.tail(l) // [2, 3]
```

function flat_map(xs, f)

Maps a function over a list and optionally flattens the result by one level.

Example:
```vv
let l = [1, 2]
list.flat_map(l, fun (i, x) [x, x * 2] end) // [1, 2, 2, 4]
```

function init(n, f)

Creates a list of size `n`, initializing each element using the function `f(index)`.

Example:
```vv
list.init(3, fun (i) i * 2 end) // [0, 2, 4]
```

function max(xs, f)

Returns the element that produces the maximum value when `f(element)` is applied.

Example:
```vv
let l = [1, 5, 2]
list.max(l, fun (x) x end) // 5
```

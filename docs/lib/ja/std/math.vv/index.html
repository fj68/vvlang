Home / Module std/math.vv

The `math` module provides standard mathematical functions.

Exports

extern floor

Returns the largest integer less than or equal to `n`.

Example:
```vv
math.floor(3.7) // 3.0
math.floor(-3.2) // -4.0
```

extern ceil

Returns the smallest integer greater than or equal to `n`.

Example:
```vv
math.ceil(3.2) // 4.0
math.ceil(-3.7) // -3.0
```
